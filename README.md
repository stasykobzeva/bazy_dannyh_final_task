# bazy_dannyh_final_task
Итоговое домашнее задание по базам данных


***1) users (Пользователи)***  

Информация о зарегистрированных пользователях системы.  
Основные поля:  

    -user_id, 
    -username, 
    -email,
    -пароль, дата создания.
***2)categories (Категории)***  

Категории для доходов и расходов, создаваемые пользователями.  

Основные атрибуты:  

    -user_id (владелец)
    -category_id,
    -name,
    -type ('Income' или 'Expense'), 
***3) accounts (Счета)***  

Банковские или иные счета пользователя.  
Основные атрибуты:   
    -account_id, 
    -user_id, 
    -name, type, баланс, дата создания.  
    
***4)transactions (Транзакции)***  

Записи о доходах и расходах по счетам.  
Основные атрибуты:  

    -transaction_id,
    -account_id,
    -category_id,
    -amount, date, описание, тип ('Income' или 'Expense').
***5)budgets (Бюджеты)***  

Планируемые лимиты по категориям. Достаточно удобно для 
Основные атрибуты:  

    -budget_id, 
    -user_id, category_id, сумма, период, даты начала и конца.  
    
***6)savings (Сбережения)***  

Цели по накоплению денег.  

    Основные атрибуты: saving_id, user_id, имя, целевая сумма, текущая сумма, дата создания, срок.
***7)income_sources (Источники доходов)***  

Источники доходов пользователя.
  Основные поля: income_source_id,  
    -user_id,
    -название,  
    -описание.
recurring_transactions (Периодические транзакции)  
***8) Повторяющиеся доходы или расходы.***
Основные поля: recurring_id, account_id, category_id, сумма, частота, следующая дата, дата последней оплаты, тип.


| **Связь** | Описание | Тип отношения | Пример |
|------------|------------|----------------|---------|
| **Пользователь — Категории** | Один пользователь может создавать множество категорий (Income/Expense) | 1:N | Один пользователь — много категорий |
| **Пользователь — Счета** | Один пользователь может иметь несколько счетов | 1:N | Один пользователь — много счетов |
| **Счета — Транзакции** | Один счет содержит множество транзакций | 1:N | Один счет — много транзакций |
| **Категории — Транзакции** | Каждая транзакция связана с одной категорией | 1:N | Одна категория — много транзакций |
| **Пользователь — Бюджеты** | Каждый пользователь может создавать несколько бюджетов | 1:N | Один пользователь — много бюджетов |
| **Категории — Бюджеты** | Каждый бюджет связан с одной категорией | 1:N | Одна категория — много бюджетов (у разных пользователей) |
| **Пользователь — Сбережения** | Каждый пользователь может иметь несколько целей | 1:N | Один пользователь — много целей |
| **Пользователь — Источники доходов** | Каждый пользователь — может иметь несколько источников доходов | 1:N | Один пользователь — много источников |
| **Счета — Периодические транзакции** | Один счет — множество периодических транзакций | 1:N | Один счет — много периодических транзакций |

Для этого надо объединить следующие таблицы:
1. transactions — содержит транзакции
2. categories — содержит категории транзакций
